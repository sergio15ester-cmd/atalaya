# Atalaya — AI Trading Lab

Laboratorio colaborativo de investigación financiera para tres integrantes humanos y agentes especializados de IA.

Estado: diseño inicial. Solo simulación sin apalancamiento. No hay cuentas conectadas ni autorización de operaciones reales.

La documentación, los límites propuestos y las plantillas se incorporarán mediante una Pull Request para revisión. El capital exacto, los integrantes y el proveedor de datos están pendientes de configuración.

No incluir datos personales, credenciales ni registros de operaciones reales mientras este repositorio sea público.
